# 童軍支部內容查核（VSBADGE 殘留清理）

ScoutBadge 的程式骨架源自 VSBADGE（深資童軍支部）及其後的 roverbadge，早期版本直接把 VSBADGE 的獎章清單、表格與角色用語搬過來。本文件記錄 **2026-10 全面查核**的範圍、發現與修正，作為日後新增功能時的檢查清單。

> 原則：**凡涉及獎章、項目、表格、班級名稱，一律以《童軍支部訓練綱要》（2026 年修訂版，P022/2026）及香港童軍總會青少年活動署的童軍支部表格為準，不得沿用深資童軍／樂行童軍支部或 VSBADGE 的寫死內容。**

## 2. 已修正的 VSBADGE／舊制殘留

### 2.1 可勾選權限彈窗（最嚴重）

原清單寫死為：

- 會員章（全部 12 項）、會員章-保護兒童（必修）
- **肩章（基礎技能 23 項）**
- 活動策劃進度項目（舊自立）、社會服務進度項目（舊責任）
- **多元技能-範疇一／二／三、戶外探險進度項目**
- **總領袖獎章 全部進度項目（佔用 L4）**、活動策劃／多元技能進度項目

後果：真正的 **童軍探索／標準／高級獎章** 無法授權，總領袖獎章被綁在 L4。

現時清單由 `data/items.json` 即時產生，並按綱要分組：

| 獎章 | 項目數 | 分組 |
|---|---|---|
| 會員章 | 11 | 單一範疇 |
| 童軍探索獎章 | 14 | A 戶外挑戰／B 個人發展／C 領導才與靈性發展／D 服務與環境 |
| 童軍標準獎章 | 16 | A／B／C／D／E 國際視野／F 探索新知 |
| 童軍高級獎章 | 17 | A／B／C／D／E／F |
| 總領袖獎章 | 17 | A／B／C／D／E／F |

儲存規則：整章全選 → 記 `L5`；局部 → 記範圍（如 `L3-A`，以現有前綴比對涵蓋 `L3-A1`）；全不選 → `NONE`（避免空字串被當成「領袖全部」）。「其他獎章」權限不會再誤蓋進度性獎章。

## 5. 日後新增／修改功能的檢查清單

1. **不要寫死獎章清單**：一律由 `data/items.json` 產生（權限、下拉、表格、統計）。
2. **項目 ID 只用 2026 制**：`L1-M1…M11`、`L2-*`…`L5-*`、`SC-INT/PUR/SER/INS/SEA/AIR/OTH-xxx`。
3. **表格只用童軍支部三款**：PT/18、P120A1、P120A2；不得加入深資／樂行／幼童軍表格。
4. **角色用語**：旅長（GSL）、童軍團長（SL）、童軍成員；避免單獨用「團長」指 GSL。
5. **簽署欄位**：PT/18 = 申請者／旅長或童軍團長提名／區總監推薦／地域總監確認／青少年活動總監批核；P120A1 = 申請人＋童軍團長副署／主考／獲授權人士。
6. **示範及測試資料**：用現行項目 ID，勿沿用 `L1-ACT-01` 等舊編號。
